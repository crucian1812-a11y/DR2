# DR2 — открытка для мамы в VR

Детская открытка на день рождения: рисунок Глеба оживает прямо в браузере
телефона. Никакого приложения ставить не надо — открывается по ссылке.

## Как это работает

1. Стартовый экран, кнопка «Открыть открытку». По ней включается звук и
   запрашивается доступ к гироскопу.
2. Начинает играть голос Глеба (40 секунд). Внизу, «на столе», лежит его
   рисунок.
3. Нужно посмотреть на рисунок — навести на него центр экрана и задержать
   на секунду. Лист поднимается, разворачивается к зрителю и превращается
   в ту же картинку, нарисованную по мотивам детской. Небо светлеет,
   выходит солнце, летят сердечки.
4. Дальше можно оглядеться: вокруг висят три семейных фото полароидами.
   Если посмотреть на фото — оно приближается.

Если на рисунок так и не посмотрели, через 25 секунд он оживает сам.

## Кнопки

| | |
|---|---|
| 🔊 | звук вкл/выкл |
| VR | стерео-режим для картонных очков: экран делится на два глаза, включается полный экран и альбомная ориентация |
| ⌖ | развернуть открытку к себе, если потерялась |
| ↺ | начать сначала |

## Как открыть на телефоне

Проще всего — GitHub Pages: в настройках репозитория Settings → Pages →
Source: ветка с этим кодом, папка `/`. Через минуту появится адрес вида
`https://crucian1812-a11y.github.io/DR2/`, его и отправляем маме.

Важно: гироскоп работает только по HTTPS, так что открывать надо именно по
ссылке Pages, а не с флешки.

Локально для проверки:

    python3 -m http.server 8000
    # и открыть http://localhost:8000

## Что где лежит

    index.html            сцена и веб-интерфейс
    css/style.css         стартовый экран, подсказки, кнопки
    js/config.js          тексты, пути к файлам, подписи к фото — правится руками
    js/components.js      компоненты A-Frame: текст, сердечки, искры, облака, стерео
    js/scene.js           сценарий: старт, превращение, фото, звук
    vendor/aframe.min.js  A-Frame 1.7.0, лежит внутри проекта — чтобы не зависеть от CDN
    assets/images/        рисунок, картинка-превращение, фото (сжатые)
    assets/audio/gleb.m4a голос Глеба
    assets/original/      исходники как загружены, на всякий случай

## Что можно поправить без программиста

Всё в `js/config.js`:

- `title`, `from` — надписи на стартовом экране;
- `photos` — список фото: файл, подпись и угол, на котором фото висит вокруг
  зрителя (0 — прямо перед ним, 90 — справа, 180 — за спиной);
- `captions` — субтитры к голосу. Пока пусто. Если вписать, например
  `[{ at: 0, text: 'Мамочка, с днём рождения!' }]`, текст появится внизу на
  нулевой секунде и будет висеть до следующей реплики.

## Про телефоны

- Android, Chrome: работает всё, включая полный экран и поворот в альбом.
- iPhone, Safari: гироскоп спросит разрешение — надо согласиться. Полный
  экран iOS не даёт, поэтому в VR-режиме сверху останется полоска браузера.
  На картонные очки это почти не влияет.
- Стерео-режим нарисован без линзовых искажений: для простых картонных
  очков нормально, для дорогих линз картинка будет слегка выпуклая.

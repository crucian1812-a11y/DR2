# DR2 — открытка для мамы в VR

Детская открытка на день рождения мамы: VR-сцена, которая открывается прямо
в браузере телефона. Ребёнок надевает картонные очки (или просто смотрит на
экран) — и попадает внутрь открытки.

## Что должно получиться

- Открывается по ссылке в мобильном браузере, без установки приложения.
- Два режима: обычный просмотр с экрана и VR/картон (стерео + гироскоп).
- Веб-интерфейс вокруг сцены: кнопка входа в VR, звук, подсказки.
- Содержимое открытки — фото, надписи, музыка, поздравление.

## Структура

    assets/images/   — фото, картинки, текстуры
    assets/audio/    — музыка и голосовое поздравление
    assets/models/   — 3D-модели, если появятся

Технологию сцены ещё не выбирали. Файлы можно складывать в `assets/` уже сейчас.
